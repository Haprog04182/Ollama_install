Get Started

Installation Protocol

01 // ACQUIRE

Загрузка ядра

Выберите удобный способ установки Ollama в вашу систему:

Download .exe
irm https://ollama.com/install.ps1 | iex
02 // INITIALIZE

Развертывание

Запустите OllamaSetup.exe. Система настроит PATH автоматически. Убедитесь, что Ollama запущена (иконка в трее).

03 // VERIFY

Валидация

Откройте PowerShell и проверьте статус установки:

ollama --version
04 // EXECUTE

Запуск модели

Инициализируйте первую модель для теста:

ollama run llama3

Pi Agent Integration

Синхронизация Интеллекта

Свяжите мощь локальных моделей с интеллектом Pi Agent для автоматизации кодинга и управления системой.

  • Откройте PowerShell и выполните:
    ollama launch pi
  • Агент автоматически подключится к локальному API Ollama.
  • В настройках Pi Agent подтвердите Endpoint.
  • Теперь агент имеет прямой доступ к вашим локальным моделям.
