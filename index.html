Installation
Protocol

Инструкция по развертыванию нейросетевого ядра Ollama. От первичной установки до превращения вашего ПК в автономный AI-центр.

01 // ACQUIRE

Загрузка ядра

Выберите удобный способ установки Ollama в вашу систему:

Метод A: Инсталлятор

Классический .exe файл для быстрой установки.

Download .exe
Метод B: PowerShell

Командная строка для продвинутых пользователей.

winget install ollama
02 // INITIALIZE

Развертывание

Запустите OllamaSetup.exe. Система настроит PATH автоматически. Важно: Убедитесь, что Ollama запущена (иконка в трее) перед использованием команд.

03 // VERIFY

Валидация

Откройте PowerShell и проверьте статус установки:

ollama --version
04 // EXECUTE

Запуск модели

Инициализируйте первую модель для теста:

ollama run llama3

Pi Agent Integration

Свяжите мощь локальных моделей с интеллектом Pi Agent для автоматизации кодинга и управления системой.

Быстрый старт через Ollama

Ollama позволяет развернуть агентскую среду напрямую через консоль. Это самый быстрый способ инициализации.

  • 01 Откройте PowerShell и выполните команду для запуска агента:
    ollama launch pi
  • 02 После загрузки агент будет автоматически подключен к локальному API Ollama.
  • 03 В настройках Pi Agent (UI) подтвердите Endpoint: http://localhost:11434.
  • 04 Теперь агент имеет прямой доступ к вашим локальным моделям.

One-Click Deployment

Для тех, кто предпочитает автоматизацию. Скопируйте этот скрипт и вставьте в PowerShell (от имени администратора). Он скачает Ollama, установит её, обновит пути системы и загрузит Llama 3.

# Ollama Auto-Install Script (Improved) $url = "https://ollama.com/download/OllamaSetup.exe" $outPath = "$env:TEMP\OllamaSetup.exe" Write-Host "--> Downloading Ollama..." -ForegroundColor Cyan Invoke-WebRequest -Uri $url -OutFile $outPath Write-Host "--> Installing Ollama..." -ForegroundColor Cyan Start-Process -FilePath $outPath -ArgumentList "/S" -Wait # Update PATH for current session to avoid 'command not found' $env:Path += ";$env:LocalAppData\Programs\Ollama" Write-Host "--> Waiting for service to initialize..." -ForegroundColor Cyan Start-Sleep -Seconds 15 Write-Host "--> Initializing Llama3 model..." -ForegroundColor Cyan & ollama run llama3 "Hello! Setup complete." Write-Host "SUCCESS: Ollama is now active!" -ForegroundColor Green
